Projektisuunnitelma

Etusivu | GitHub | Projektisuunnitelma | Taitaja | Loppuraportti

Laadi projektin alussa suunnitelma. Tallenna valmis projektisuunnitelma omaan GitHub-repoosi.

Projektisuunnitelmassa vastaat ainakin seuraaviin kysymyksiin.

1. Tavoite

  • Mikä on projektisi aihe?
  • Mitä haluat projektin aikana oppia?
  • Millaisen lopputuloksen aiot tehdä?
  • Miten projektin onnistumista voidaan arvioida?

2. Tiedonhaku ja materiaalit

Selvitä etukäteen, millaista materiaalia aiheesta löytyy.

Voit hyödyntää esimerkiksi:

  • dokumentaatioita
  • oppaita ja tutoriaaleja
  • verkkokursseja
  • videoita
  • kirjoja

Kirjaa suunnitelmaan tärkeimmät lähteet ja materiaalit, joita aiot käyttää.

3. Aikataulu

Laadi projektille realistinen aikataulu.

Jaa työ esimerkiksi viikoittaisiin tavoitteisiin:

Viikko Tavoite
1 Aiheeseen tutustuminen
2 Kehitysympäristön käyttöönotto
3–4 Ensimmäinen toimiva versio
5–6 Ominaisuuksien toteutus
7 Testaus ja viimeistely
8 Esittely ja dokumentointi

Aikataulu saa muuttua projektin aikana. Muutoksista kannattaa kuitenkin pitää kirjaa.

4. Riskit

Mieti etukäteen, mikä projektissa voi mennä pieleen.

Esimerkiksi:

Riski Vakavuus Miten ehkäisen?
Ohjelmistossa ilmenee ongelmia Keskisuuri Käytän versionhallintaa ja varmuuskopioita
Tekniikka osoittautuu liian vaikeaksi Suuri Rajaan projektin laajuutta
Aikataulu ei riitä Keskisuuri Teen ensin toimivan perusversion
Ohjelmistossa ilmenee ongelmia Keskisuuri Käytän versionhallintaa ja varmuuskopioita

5. Mahdollisuudet ja työelämä yhteys

Selvitä, mitä hyötyä valitsemastasi tekniikasta voi olla.

  • Mitä mahdollisuuksia tekniikka tarjoaa?
  • Missä sitä käytetään?
  • Millaisia sovelluksia sillä voidaan tehdä?
  • Millaisia osaajia tarvitaan?
  • Pyri löytämään 3–5 työpaikkaa tai yritystä, joissa valitsemaasi tekniikkaa hyödynnetään.

6. Työvälineet Kirjaa projektin käyttämät työvälineet.

Esimerkiksi:

  • Visual Studio Code
  • GitHub
  • Node.js
  • React
  • Godot
  • Blender

Merkitse ohjelmien versiot, jos ne ovat tiedossa.

Kirjaa myös, missä projektin tiedostot sijaitsevat:

  • GitHub
  • OneDrive
  • muu sovittu tallennuspaikka.
