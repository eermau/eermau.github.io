1. Mikä on portfolioprojekti?

Projektityössä saat mahdollisuuden kehittää omaa osaamistasi sinua kiinnostavassa aiheessa.

Tavoitteena on opetella jokin uusi ohjelmointiin, ohjelmistokehitykseen tai ohjelmistotuotantoon liittyvä asia ja soveltaa sitä käytännön projektissa.

Projektityö kuuluu tutkinnon osaan Ohjelmiston toteuttaminen komponenttikirjastolla 30 osp.

Projektin aikana:

  • valitset itseäsi kiinnostavan aiheen
  • tutustut uuteen tekniikkaan, ohjelmointikieleen, työvälineeseen tai toimintatapaan
  • suunnittelet ja toteutat projektin
  • dokumentoit työskentelyäsi
  • esittelet työsi
  • laadit projektista loppuraportin

Kirjallisia osuuksia ovat projektisuunnitelma ja loppuraportti. Työ palautetaan GitHubin kautta.

2. Aiheen valinta

Mieti ensin: Mitä haluaisin oppia?

Aiheen tulisi pääsääntöisesti liittyä ohjelmointiin tai ohjelmistotuotantoon. Projektin ei tarvitse olla valtavan suuri. Tärkeintä on, että opit työn aikana jotain uutta ja pystyt osoittamaan oppimisesi käytännön projektilla.

Esimerkkejä aiheista

Web-kehitys
  • uudet JavaScript-teknologiat
  • React
  • Node.js
  • PHP
  • Laravel
  • erilaiset web-kehityksen työkalut
Sovelluskehitys
  • Windows-sovellukset
  • Visual Studio
  • Java
  • muut ohjelmointikielet ja kehitysympäristöt
Pelikehitys
  • Godot
  • Unity
  • Blender
  • pelien grafiikka ja ohjelmointi
Mobiilikehitys
  • Android Studio
  • React Native
  • mobiilisovelluksen suunnittelu ja toteutus
Laitteet ja palvelimet
  • Raspberry Pi
  • sulautetut järjestelmät
  • palvelimet
  • ohjelmiston ja laitteiston yhdistäminen
Voit myös ehdottaa jotakin muuta aihetta. Keskustele aiheesta opettajan kanssa ennen työn aloittamista.

3. Projektin eteneminen

Projektityö etenee pääpiirteissään näin:

  1. Aiheen valinta
  2. Projektisuunnitelma
  3. Tiedonhaku ja uuden asian opettelu
  4. Projektin toteuttaminen
  5. Työn esittely
  6. Loppuraportti ja itsearviointi

Pidä projektin aikana työsi ja materiaalisi järjestyksessä. Hyödynnä GitHubia projektin versionhallinnassa ja dokumentoinnissa.

Projektisuunnitelma

Laadi projektin alussa suunnitelma. Tallenna valmis projektisuunnitelma omaan GitHub-repoosi.

Projektisuunnitelmassa vastaat ainakin seuraaviin kysymyksiin.

1. Tavoite

  • Mikä on projektisi aihe?
  • Mitä haluat projektin aikana oppia?
  • Millaisen lopputuloksen aiot tehdä?
  • Miten projektin onnistumista voidaan arvioida?

2. Tiedonhaku ja materiaalit
